# First Rung

A sample internship board for high school students. Static HTML/CSS/JS, no build step.

- **Browse** (`index.html`) — search and filter by grade, season, field, format and pay; sorted by deadline.
- **Listing** (`listing.html?id=…`) — details, eligibility check and an application checklist.
- **How to apply** (`guide.html`) — month-by-month timeline, resume tips, cold-email template.
- **My list** (`tracker.html`) — saved internships with status and notes, stored in `localStorage`.

All listings in `data.js` are fictional sample data.

Run locally: `python3 -m http.server` and open http://localhost:8000.
